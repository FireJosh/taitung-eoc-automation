# 臺東縣消防局災害應變中心 (EOC) 自動化系統

本專案旨在建立臺東縣消防局災害應變中心的自動化報告生成與資料整合系統。

## 📋 專案目標

- **報告自動彙整生成**：自動整合各局處資料，生成處置報告、重點災情報告、工作會報
- **會議記錄自動化**：運用 MS Teams / Whisper 將會議錄音轉為逐字稿並自動摘要
- **EMIC 同步 (RPA)**：使用 RPA 技術自動登打 EMIC 系統

- Python
- AI (GPT-4 / Claude)
